# BUZZIN
#### A Wireless Game Buzzer

  BUZZIN is a custom-built wireless game buzzer designed to bring the excitement of classic game shows to life! I was inspired by game show buzzers and there are no good ones out there that people have made. So designed my own that can be used wirelessly and rechargeable with the xiao esp32c5 to control each buzzer. I added a led light indicator to be able to distinguish teams or be used for other things and I added a small buzzer as well. I am thinking that multiple buzzers would use ESPNOW to connect to a main hub - a xiao esp32 c5 - to receive all the signals from the controllers. I decided for the c5 to make sourcing parts simpler since it uses the same component as the controllers. I do not have a fancy hub with lights but rather the idea was that all the sound and cool stuff can be displayed on a screen that everyone sees which would be a lot cheaper than to create another system for a hub and it means it just plugs into your computer with a simple cord and because this is customizable, you can totally change the code or design or whatever.

  I designed this after wanting to make my own game system but this will be fully customizable and wireless. So after seeing that Hack Club Fabricate can help fund projects, I immediately started on it. I used EasyEDA Pro for the PCB design and schematics and I used Fusion 360 to design the CAD for the controller cases. 

  I do not have any code ready for it however I do know it should be able to work. If I can get it funded by Fabricate, then I would spend more time on it once I have everything to code and do the finishing touches and fixing different errors in the CAD design.

# Schematic and PCB V1.5
V1.5 Smaller and more compact. Instead of vibrating, it is just a small buzzer to cut the cost and space a bit. It includes extra pins if you would like to expand the design further without having to redesign the pcb. With these extra pins, you can expand this system up to 5 buttons and can attach an LED strip or equivalent instead of a single led. With this expansion, I thought it necessary to add screw holes if needed for other designs, you can use 2 M3 screws to attach the PCB to other things.
